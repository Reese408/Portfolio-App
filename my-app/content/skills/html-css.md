# HTML & CSS

HTML and CSS are where my web development journey began. As a junior in high school, I was curious and interested in making web pages - that initial curiosity blossomed into a pure love and joy for full-stack web development. These foundational technologies remain central to everything I build, and I've continuously evolved my skills from basic HTML/CSS to modern frameworks and styling solutions.

- **Forms & Validation** - User input and accessible form design

- **CSS Modules** - Scoped styling in component-based applications

- **CSS Preprocessors** - Understanding of Sass/SCSS concepts
